01 🔥 اكتشاف بؤر الحرائق وحرق قش الأرز في دلتا النيل

الفكرة

استخدام بيانات الأقمار الصناعية لاكتشاف مناطق وتوقيتات الحرائق في دلتا النيل، خصوصًا خلال فترة حرق قش الأرز بعد موسم الحصاد.

مصادر البيانات

  • NASA FIRMS — بيانات الحرائق (Fire Hotspots)
  • Open-Meteo — بيانات الطقس

خطوات العمل

  1. تنظيف البيانات ودمج مصدري البيانات.
  2. تحديد بؤر الحرائق باستخدام خوارزمية DBSCAN.
  3. تحليل الموسمية لفهم توقيت الحرائق على مدار العام.
  4. بناء نموذج تنبؤي يتوقع الأيام ذات النشاط المرتفع بناءً على بيانات الطقس ووقت السنة.
🎯 الهدف: تحديد الأنماط الزمنية والمكانية لحرائق قش الأرز، والمساعدة في التنبؤ المبكر بأيام الخطورة العالية.

التقنيات المستخدمة

Python Pandas / Scikit-learn DBSCAN Time Series NASA FIRMS API Open-Meteo API

02 🍳 التنبؤ بوقت تحضير الطلبات الغذائية

الفكرة

بدلًا من التنبؤ بوقت توصيل الطلب، يركز المشروع على التنبؤ بالوقت الذي يحتاجه المطعم لتحضير الطلب.

البيانات والخصائص

  • المطعم
  • نوع الطعام
  • عدد الأصناف في الطلب
  • تكلفة الطلب
  • وقت وتاريخ الطلب

خطوات العمل

  1. جمع وتنظيف بيانات الطلبات.
  2. هندسة الخصائص (Feature Engineering).
  3. بناء نموذج Machine Learning للتنبؤ بمدة التحضير.
  4. (اختياري) قاعدة بيانات لإدارة المطاعم والطلبات.
  5. (اختياري) Dashboard أو Deployment لعرض التوقعات.
🎯 الهدف: مساعدة المطاعم ومنصات التوصيل على تقدير وقت التجهيز بدقة أكبر، وتقليل التأخير.

التقنيات المستخدمة

Python Scikit-learn / XGBoost SQL Database Streamlit / Flask

03 🚗 نظام ذكي لاختيار وتسعير السيارات المستعملة

الفكرة

تطوير المشروع من مجرد "التنبؤ بسعر السيارة" إلى نظام متكامل يساعد المستخدم على اختيار السيارة المناسبة له.

آلية العمل

يدخل المستخدم متطلباته (الميزانية، نوع الوقود، ناقل الحركة، طبيعة الاستخدام)، ويقوم النظام بـ:

  1. ترشيح السيارات المناسبة لمتطلبات المستخدم.
  2. التنبؤ بالسعر العادل للسيارة المرشحة.
  3. (اختياري) حساب الأقساط بناءً على الميزانية.

خطوات العمل

  1. جمع بيانات أسعار السيارات المستعملة.
  2. هندسة الخصائص.
  3. بناء نموذج تنبؤ بالسعر.
  4. بناء نظام توصية لترشيح السيارات.
🎯 الهدف: مساعدة المستخدم على اختيار السيارة الأنسب بناءً على احتياجاته وميزانيته، لا مجرد معرفة سعر سيارة بعينها.

التقنيات المستخدمة

Python Feature Engineering Recommendation System Regression Models
